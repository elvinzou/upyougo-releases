## 到点了，在猫咪身边提醒

<p align="center"><img src="assets/reminder-bubbles.png" width="900" alt="起身和坐下提醒气泡预览，展示猫咪左右两侧布局及确认、稍后提醒按钮"></p>

- **不抢输入焦点**：提醒出现时，你可以继续当前的输入。

- **忙的时候可以稍后**：延后 2 / 5 / 10 分钟，或使用免打扰。

## 小猫会怎样回应你？

| 场景 | 动作与反馈 |
| --- | --- |
| 没有操作，正常陪伴 | 自主轮换抬头、甩尾和眨眼，无需一直移动鼠标 |
| 鼠标靠近 | 抬头，并朝鼠标所在的一侧歪头看你 |
| 轻点摸摸 | 闭眼、蹭头、交替动前爪、抬下巴，再回到放松姿态 |
| 再摸一下 | 当前动作继续完成，最多追加一轮回应，不会反复从头播放 |
| 起身提醒到点 | 伸出前爪、展开身体，配合起身提醒 |
| 坐下提醒到点 | 做出收拢、安定下来的动作，配合坐下提醒 |
| 偶尔的大动作 | 打哈欠、伸展或抬爪招手；动作之间留有间隔 |
| 拖动 / 暂停 | 可以拖动到合适位置；暂停时降低自主动作频率 |

应用尊重 Windows 的减少动态效果设置：关闭自主动画，保留短暂的静态触摸回应。小猫不会检测你的身体姿势，计时阶段仍由你主动确认。

## 安装

1. 在 Releases 下载 **UpYouGo-Setup.exe**。
2. 选择独立、可写的安装目录，例如 `D:\Apps\UpYouGo`，点击安装。
3. 设置坐站时间及工作日程，开始计时。

需要 Windows x64、.NET Framework（建议 4.8）和 Microsoft Edge WebView2 Runtime。安装器不附带完整 WebView2 Runtime。关闭主面板不会退出；右键托盘小猫可退出。

## 功能

- 坐站交替计时，暂停/继续、确认姿势和稍后提醒。
- 像素猫陪伴，气泡提醒不抢占当前输入焦点。
- 工作时段、星期、中国调休与可选午休。
- 锁屏/睡眠处理，手动及全屏自动免打扰。
- 本地统计、行为反馈和开机启动选项。
- 托盘菜单支持将设置与统计导出为 `.upyougo` 备份文件，并从备份恢复；恢复前会校验文件且留存当前数据副本。
- 自定义目录、新版提示、在线/本地更新及失败回退。

## 在线更新

安装版启动后及每 6 小时检查此仓库的正式 Release。点击托盘更新通知或“版本与更新”，查看说明后下载更新。程序先校验文件，再保存退出并验证新版；失败恢复原安装状态。

如果 1.2.2 的“版本与更新”仍显示“操作已被用户取消”，请从 [1.2.3 发布页](https://github.com/elvinzou/upyougo-releases/releases/tag/v1.2.3)手动下载并运行 `UpYouGo-Setup.exe` 一次。安装会保留设置与统计。

`UpYouGo-Windows-x64.zip` 可用于便携运行或本地更新。`.sha256` 是更新校验文件，普通用户无需手动操作。GitHub 自动提供的 Source code 压缩包仅包含本仓库文档，不是安装包。

## 数据与限制

个人设置和统计留在 `%APPDATA%\LumbarReminder`，更新不删除它们；这些记录不上传。联网用于版本检查、下载及日历同步。

更新不接续原倒计时，重启遵循启动设置。目前尚无完整卸载与旧版本自动清理入口。此仓库仅用于公开软件分发和使用文档，完整开发源码保持私有。

问题反馈请描述 Windows 版本、应用版本、重现步骤及错误提示，勿在公开 Issue 中附带个人数据或凭证。
