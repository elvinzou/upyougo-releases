# 数据与网络说明

适用范围：UpYouGo 1.4.0，GitHub 独立安装版。

## 本地保存什么

设置、日程偏好、桌宠名字与外观、时间统计、提醒响应行为记录及日历缓存保存在 `%APPDATA%\LumbarReminder`。导入的角色位于 `characters` 子目录。WebView2 浏览器组件数据位于 `%LOCALAPPDATA%\UpYouGo\WebView2Data`。

程序不要求注册账号，不上传个人设置、统计或行为记录。姿势由用户确认，不使用摄像头或传感器自动识别。

## 什么时候联网

- 向公开 GitHub 发布仓库查询版本与附件。
- 用户选择更新时下载程序包、校验文件。
- 按启用的日历功能同步工作日历。

这些请求会连接对应服务，遵循系统和网络组件的连接行为；本项目不把联网描述成完全离线。网络不可用时，可继续使用核心提醒与已有本地数据，日历按已有缓存及回退规则处理。

## 备份、迁移与删除

托盘可导出个人数据备份并恢复。当前备份包含设置与统计/行为记录，不包含自定义角色素材、日历缓存、Windows 自启动注册表项或浏览器组件缓存。恢复前保存现有数据副本；更新和回退保留个人数据。

迁移自定义角色请保留原角色包。手动管理数据前退出程序，按需要另行保留副本。目前没有完整的卸载与旧版本自动清理入口。

## 公开反馈

反馈问题时，提供版本、操作步骤与错误信息即可。设置、统计、备份文件可能包含个人使用信息，无需作为常规问题反馈附件公开。
