# 功能需求与验收口径

[English](../i18n/en/REQUIREMENTS.md) | [日本語](../i18n/ja/REQUIREMENTS.md) | [한국어](../i18n/ko/REQUIREMENTS.md) | **简体中文** | [繁體中文](../i18n/zh-Hant/REQUIREMENTS.md)

基线：UpYouGo 1.2.0，2026-09-23。本文描述当前 Windows 桌面产品；建议需求见 [后续规划](ROADMAP.md)。历史 PRD 的硬件范围不属于本版交付。

## 产品目标与用户流程

为使用 Windows 长时间办公的人提供低打扰的坐站交替提醒。用户自行确认实际姿势，程序不通过摄像头或传感器判断是否站起。

首次运行 → 设置坐站时长与工作日程 → 开始计时 → 桌宠旁提醒 → 确认站起/坐下 → 下一轮。工作之外、午休、离开电脑及免打扰按各自规则处理，避免重复或不合时宜的提示。

## 已实现需求

| ID | 能力 | 验收口径 |
| --- | --- | --- |
| R01 | 坐站交替计时 | 可配置坐姿/站姿时长；支持开始、暂停、继续及重新开始；确认动作才切换姿势 |
| R02 | 低打扰提醒 | 提醒气泡跟随桌宠附近显示，不抢占当前输入焦点；主题与主面板协调 |
| R03 | 稍后提醒 | 支持延后 2/5/10 分钟，不因每秒刷新丢失延后状态 |
| R04 | 工作日程 | 可配置工作时段、星期、可选午休；工作日程之外不累计有效坐站时长 |
| R05 | 中国调休 | 支持中国节假日/调休及今天工作或休息的覆盖；同步失败保留已有缓存，未覆盖年份回退星期规则 |
| R06 | 离开电脑 | Windows 锁屏、睡眠时冻结计时；重叠事件合并；短离开续计，长离开等待用户选择 |
| R07 | 免打扰 | 支持手动免打扰和可关闭的全屏自动静默；两者独立，自动静默结束不取消手动设置 |
| R08 | 本地统计 | 提供日/周/月/年统计，记录有效区间及提醒响应等行为反馈；不向服务器上传这些记录 |
| R09 | 桌宠 | 可拖动像素猫、待机及互动动作、提醒姿态；考虑减少动态效果设置 |
| R10 | 启动设置 | 可配置开机启动与启动时自动计时；关闭主面板不退出，托盘可退出 |
| R11 | 安装 | 可选择独立可写目录，创建固定启动入口和快捷方式；已有个人数据继续使用 |
| R12 | 发现新版 | 已安装客户端启动后及每 6 小时检查公开正式 Release；仅较新版本提示，不安装预发布版 |
| R13 | 在线更新 | 展示版本说明；用户点击后下载 ZIP，验证发布校验值和内部清单，再保存退出、启动新版 |
| R14 | 本地更新 | 可以选择完整 ZIP；拦截文件缺失、路径越界、重复文件、校验失败及同版本不同内容 |
| R15 | 失败回退 | 新版主面板加载通过且短暂存活后确认；启动失败恢复原状态；下次启动恢复中断事务；支持手动回退 |
| R16 | 语言切换 | 1.2.0 新增中文 / English 界面切换。主面板右上角选择语言，立即生效并记住选择；已有用户默认继续使用中文。切换保留计时进度、姿势和统计，不改变中国工作日历或其他日程设置。 |

## 不属于当前版本

手机正式 App、跨设备同步、云账户、姿势自动识别、在线强制更新、更新后续接原计时、完整卸载器均未交付。ESP8266 硬件项目和旧桥接代码保留为历史工程，不编入本版主程序。

## 更新异常与数据边界

- 下载和清单验证在退出旧版之前完成，失败不会切换当前版本。
- 保存失败时保持旧程序运行，不强制结束既有进程。
- 启动验证超时为 30 秒；只结束本次更新器启动的失败进程。
- 回退不迁移、删除或恢复个人数据。后续出现不兼容的数据格式时，必须先提供备份和兼容方案。
- 旧便携版无退出接口时，提示用户从托盘退出。
- 安装目录无权限或存在冲突文件时提示选择其他目录，不自动提权。

## 验证与指标

验证范围见各版本发布说明。响应统计是基于用户确认的本地观察，不等于真实活动或健康效果。当前没有留存率、健康收益或公开用户规模的验证数据，不将这些作为已达成结果。
