# 桌宠与本地角色包

主面板底部的「桌宠设置」提供角色卡片、独立动作试播、改名、70%–150% 大小和贴边开关。首批内置像素猫、九千岁、手绘水豚和中性 Q 版伙伴。九千岁使用照片参考素材与专属连续动作，保持外观比例。适用于 GitHub 独立安装版 1.4.0。

单击立即摸摸；双击沿用 Windows 的双击判定打开主面板，第二次点击不叠加摸摸。拖动超过 4 像素才视作拖放，拖动不会触发点击。右键提供摸摸、零食和玩球，每次一段，不排队。短句气泡不抢焦点，提醒、拖动、隐藏或免打扰会收掉短句。

拖至当前显示器工作区的左、右边缘 28 像素内松手后收起，保留约 45% 窗口宽度可见。鼠标靠近时展开；移开后收回。收起区域裁在当前显示器内，不泄露到相邻屏幕。提醒出现时先展开再放置确认气泡；确认后短暂回应，再恢复贴边。托盘「找回桌宠」取消本次贴边并返回可见工作区，全屏期间延后显示；全屏结束即可恢复，提醒另行保留恢复缓冲。屏幕布局改变时重新检查位置。关闭贴边可立即展开。

## 角色包结构

可导入文件夹或 ZIP。ZIP 根目录直接放配置，或只含一个外层文件夹。个人角色保存在 `%APPDATA%\LumbarReminder\characters\<id>`，与程序目录分离，更新和回退不删除这些文件。角色 ID 重复时拒绝导入，保留原角色；不会自动覆盖已有包。桌宠偏好同时保存在独立的 `pet-preferences.ini` 中；回退到旧版后，即使旧版保存设置时丢掉未知字段，切回新版仍能恢复角色、名字、大小与贴边偏好。恢复仅补桌宠字段，不覆盖旧版改动过的计时设置。内置猫和狗通过适配器保留已有渲染方式，用户角色统一使用以下数据格式，无脚本或插件执行入口。

```text
my-companion/
  character.json
  idle.png
  happy.png
  preview.png          # 可选的独立缩略图
```

最小示例（两张透明 PNG 均为 256×256）：

```json
{
  "version": 1,
  "id": "my-companion",
  "name": "我的伙伴",
  "nameEn": "My companion",
  "description": "一位安静的伙伴。",
  "descriptionEn": "A quiet companion.",
  "author": "Your name",
  "license": "Your license",
  "rendering": "smooth",
  "baseWidth": 256,
  "baseHeight": 256,
  "anchorX": 128,
  "anchorY": 240,
  "actions": {
    "idle": [{ "image": "idle.png", "duration": 2500 }],
    "pet": [{ "image": "happy.png", "duration": 900 }]
  },
  "lines": {
    "pet": ["谢谢摸摸！"],
    "pet-en": ["Thanks for the pets!"]
  }
}
```

`preview` 可指定独立 PNG 缩略图；未指定时自动绘制待机姿态。`rendering` 使用 `pixel` 保持像素清晰，或 `smooth` 平滑缩放。所有帧共享 `baseWidth`、`baseHeight` 画布和脚底锚点，整体等比放入桌宠窗口，不对单独姿态拉伸。空白边距、四肢、食物与玩具都保留，不做“只取最大连通区域”的处理。

帧可选择图集中的矩形，并放在公共画布上：

```json
{ "image": "atlas.png", "x": 300, "y": 0, "width": 180, "height": 220,
  "offsetX": 38, "offsetY": 20, "duration": 120 }
```

`x/y/width/height` 是原图像素坐标；`offsetX/offsetY` 是公共画布上的位置。不指定矩形时使用整张图；位移默认 0。所有矩形必须完整落在原图片与公共画布中。请按同一比例制作姿态，通过位移对齐脚底，不要分别按外接框缩放。

| 动作键 | 含义 |
| --- | --- |
| `idle` | 必需的待机；可循环连续帧 |
| `blink`, `look`, `greet` | 自主眨眼、关注和问候 |
| `pet`, `feed`, `play` | 摸摸、进食和逗玩 |
| `drag`, `drop` | 提起与落稳 |
| `stand`, `sit` | 坐站提醒；提醒存在时保持最后一帧 |
| `confirm` | 真实确认后的一次回应 |
| `rest` | 午休、非工作时段等安静状态 |

缺少可选动作时回到待机，提醒气泡仍提供完整文字和确认操作。普通互动不能覆盖提醒；拖动暂时使用提起姿态，放下后恢复提醒。动态效果减少时停用自主动作和姿态过渡，明确互动保留静态反馈。试播完全独立于真实计时和统计。

## 校验与资源限制

- 配置版本为 1；ID 为 2–64 位小写字母、数字和连字符，首位为字母或数字。
- 名称最多 64 字，描述最多 512 字；公共画布每边 16–1024 像素。
- 图片必须为带 alpha 或透明调色板的 PNG，每边不超过 4096 像素；解码前先检查 PNG 头部尺寸。
- 最多 48 张被引用图片，合计最多 3200 万像素；单个文件最多 16 MiB，整个包最多 48 MiB、96 个文件/目录。
- 最多 32 个动作、每动作 256 帧、总计 1024 帧；每帧 30–10000 毫秒。普通互动最多播放 4 秒，随后回到当前基础状态。
- 仅接收 PNG、JSON、TXT、MD 文件。拒绝绝对路径、越界路径、链接、重复 ZIP 路径和 Windows 数据流路径。
- 导入先写入独立暂存目录，完成配置与被引用图片校验后再移动到正式目录。失败清理暂存文件，不改变当前选择与计时。设置与桌宠偏好均先写临时文件，再替换；偏好文件提交失败时回滚主设置。

## 实现与验收

`PetCharacters.cs` 负责角色加载、导入、通用动作、预览与短句；`CompanionForm` 保留原生透明窗口、输入和贴边；`ReminderContext` 保存偏好并维持坐站规则。姿态过渡为 140 毫秒透明度过渡，贴边使用与主面板相同的 `cubic-bezier(.23,1,.32,1)`、200 毫秒移动，均支持减少动态效果。

运行 `qa/Test-PetCharacters.ps1` 验证实际素材、导入、失败保护、角色切换、缩放、独立预览和原生贴边；运行 `qa/Test-DogAppearance.ps1` 验证真实 HWND 比例、响应及带时间戳的原生窗口录制；再运行气泡和语言回归。自动测试覆盖负坐标、多屏几何及断屏位置恢复，真实多台显示器与不同 DPI 组合仍需在对应硬件上检查。
