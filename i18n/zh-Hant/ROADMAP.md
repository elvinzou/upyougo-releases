# 後續需求規劃

[English](../en/ROADMAP.md) | [日本語](../ja/ROADMAP.md) | [한국어](../ko/ROADMAP.md) | [简体中文](../../docs/ROADMAP.md) | **繁體中文**

以下是建議，不代表已實現或已承諾排期。當前基線見 [功能需求](REQUIREMENTS.md)。

| 優先順序 | 需求 | 價值與驗收方向 |
| --- | --- | --- |
| P1 | 更新後接續計時 | 儲存坐/站階段、剩餘時間、延後/暫停狀態；更新和回退後可恢復，過期會話明確處理 |
| P1 | 資料匯出與恢復 | 可匯出個人設定和統計；恢復前驗證並保留現有資料備份 |
| P1 | 安裝維護完善 | 提供解除安裝入口、舊版本空間清理、安裝目錄遷移；預設保留個人資料 |
| P2 | 下載取消與恢復 | 使用者可取消下載；弱網重試不打斷當前計時，不留下無用臨時檔案 |
| P2 | 更新偏好與渠道 | 可關閉自動檢查、忽略某次更新；維護程式本身的相容升級協議 |
| P2 | 釋出信任與執行相容 | 可執行檔案簽名、更多 DPI/多顯示器與 Windows 環境驗證 |
| P2 | 核心規則進一步剝離 | 抽出不依賴 WinForms 的計時、日程與記錄邊界，為手機端複用規則 |
| 待驗證 | 手機正式 App | 先驗證後臺提醒、通知許可權和互動需求，再決定實現範圍；不復刻桌面寵物視窗與安裝程式 |

先完成穩定分發和資料可恢復性，再擴大平臺與功能。硬體聯動目前維持歷史工程，不納入上述預設開發順序。
