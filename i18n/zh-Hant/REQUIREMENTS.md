# 功能需求與驗收口徑

[English](../en/REQUIREMENTS.md) | [日本語](../ja/REQUIREMENTS.md) | [한국어](../ko/REQUIREMENTS.md) | [简体中文](../../docs/REQUIREMENTS.md) | **繁體中文**

基線：UpYouGo 1.2.3，2026-09-28。本文描述當前 Windows 桌面產品；建議需求見 [後續規劃](ROADMAP.md)。歷史 PRD 的硬體範圍不屬於本版交付。

## 產品目標與使用者流程

為使用 Windows 長時間辦公的人提供低打擾的坐站交替提醒。使用者自行確認實際姿勢，程式不透過攝像頭或感測器判斷是否站起。

首次執行 → 設定坐站時長與工作日程 → 開始計時 → 桌寵旁提醒 → 確認站起/坐下 → 下一輪。工作之外、午休、離開電腦及免打擾按各自規則處理，避免重複或不合時宜的提示。

## 已實現需求

| ID | 能力 | 驗收口徑 |
| --- | --- | --- |
| R01 | 坐站交替計時 | 可配置坐姿/站姿時長；支援開始、暫停、繼續及重新開始；確認動作才切換姿勢 |
| R02 | 低打擾提醒 | 提醒氣泡跟隨桌寵附近顯示，不搶佔當前輸入焦點；主題與主面板協調 |
| R03 | 稍後提醒 | 支援延後 2/5/10 分鐘，不因每秒重新整理丟失延後狀態 |
| R04 | 工作日程 | 可配置工作時段、星期、可選午休；工作日程之外不累計有效坐站時長 |
| R05 | 中國調休 | 支援中國節假日/調休及今天工作或休息的覆蓋；同步失敗保留已有快取，未覆蓋年份回退星期規則 |
| R06 | 離開電腦 | Windows 鎖定畫面、睡眠時凍結計時；重疊事件合併；短離開續計，長離開等待使用者選擇 |
| R07 | 免打擾 | 支援手動免打擾和可關閉的全螢幕自動靜默；兩者獨立，自動靜默結束不取消手動設定 |
| R08 | 本機統計 | 提供日/周/月/年統計，記錄有效區間及提醒響應等行為回饋；不向伺服器上傳這些記錄 |
| R09 | 桌寵 | 可拖動像素貓、待機及互動動作、提醒姿態；考慮減少動態效果設定 |
| R10 | 啟動設定 | 可配置開機啟動與啟動時自動計時；關閉主面板不退出，系統匣可退出 |
| R11 | 安裝 | 可選擇獨立可寫目錄，建立固定啟動入口和快捷方式；已有個人資料繼續使用 |
| R12 | 發現新版 | 已安裝客戶端啟動後及每 6 小時檢查公開正式 Release；僅提示較新版本，排除預發行版；更新視窗無法啟動時顯示手動下載位址，不出現未處理例外 |
| R13 | 線上更新 | 展示版本說明；使用者點選後下載 ZIP，驗證釋出驗證值和內部清單，再儲存退出、啟動新版 |
| R14 | 本機更新 | 可以選擇完整 ZIP；攔截檔案缺失、路徑越界、重複檔案、驗證失敗及同版本不同內容 |
| R15 | 失敗回退 | 新版主面板載入透過且短暫存活後確認；啟動失敗恢復原狀態；下次啟動恢復中斷事務；支援手動回退 |
| R16 | 語言切換 | 1.2.0 新增中文 / English 介面切換。在主面板右上角選擇語言，立即生效並記住選擇；既有使用者預設繼續使用簡體中文。切換保留計時進度、姿勢與統計，不改變中國工作日曆或其他日程設定。 |
| R17 | 個人資料匯出 | 從托盤選單將設定、時間統計、行為紀錄及現有 `.bak` 副本匯出為單一 `.upyougo` 檔；若目前統計儲存失敗，不匯出不完整快照 |
| R18 | 從備份還原 | 驗證備份結構與 SHA-256；先保留現有檔案，再還原並重新載入資料；移除備份中不存在的舊統計與 `.bak`，避免混用歷史紀錄 |

工作日曆快取可重新同步，不包含在個人備份中；Windows 登入自動啟動的登錄項目也不會隨備份移轉。還原的是設定與歷史紀錄，不接續原本的計時階段。

## 不屬於當前版本

手機正式 App、跨裝置同步、雲賬戶、姿勢自動識別、線上強制更新、更新後續接原計時、完整解除安裝程式均未交付。ESP8266 硬體專案和舊橋接程式碼保留為歷史工程，不編入本版主程式。

## 更新異常與資料邊界

- 下載和清單驗證在退出舊版之前完成，失敗不會切換當前版本。
- 儲存失敗時保持舊程式執行，不強制結束既有程序。
- 啟動驗證超時為 30 秒；只結束本次更新器啟動的失敗程序。
- 回退不遷移、刪除或恢復個人資料。後續出現不相容的資料格式時，必須先提供備份和相容方案。
- 舊便攜版無退出介面時，提示使用者從系統匣退出。
- 安裝目錄無許可權或存在衝突檔案時提示選擇其他目錄，不自動提權。

## 驗證與指標

驗證範圍見各版本釋出說明。響應統計是基於使用者確認的本機觀察，不等於真實活動或健康效果。當前沒有留存率、健康收益或公開使用者規模的驗證資料，不將這些作為已達成結果。
