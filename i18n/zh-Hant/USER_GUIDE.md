# 使用說明

[English](../en/USER_GUIDE.md) | [日本語](../ja/USER_GUIDE.md) | [한국어](../ko/USER_GUIDE.md) | [简体中文](../../USER_GUIDE.md) | **繁體中文**

## 首次安裝與遷移

下載 Release 中的 UpYouGo-Setup.exe，選擇獨立可寫資料夾。支援更新介面的舊版會自動儲存退出；更早的便攜版需要先右鍵系統匣小貓退出。安裝不會刪除原設定和統計。

## 日常提醒

設定坐姿、站姿時長與工作時間後點選開始。提醒出現後選擇確認站起/坐下，進入下一階段；暫時不方便時使用稍後提醒或免打擾。姿勢由你主動確認，程式不自動檢測身體動作。

在日程設定中配置星期、中國調休、今天工作/休息以及可選午休。鎖定畫面與睡眠會凍結計時，長時間離開後需要選擇繼續或重新開始。全螢幕自動靜默可關閉。

主面板統計入口顯示本機時長和行為回饋。關閉面板會保留系統匣與桌寵執行；徹底退出請使用系統匣選單。

## 更新與回退

系統匣 → 版本與更新，可檢查新版本、檢視釋出說明並下載，也可選擇完整本機更新 ZIP。安裝程式會先驗證，再儲存退出；新版載入驗證失敗恢復原安裝狀態。回退上一版不會回退個人資料。

1.1.1 將舊預設私人儲存庫更新源遷移到本公開儲存庫。首次從舊版本遷移到此渠道建議執行本次 Setup，以同時更新維護程式。

## 個人資料備份與還原

在托盤選單將個人資料匯出為 `.upyougo` 檔。還原時程式會先驗證檔案，並在 `%APPDATA%\LumbarReminder\backups` 保存還原前的資料副本，然後重新載入設定與歷史紀錄。原本的倒數計時、工作日曆快取及 Windows 自動啟動登錄項目不會還原。

若 1.2.2 開啟「版本與更新」時仍顯示「操作已被使用者取消」，請從 [1.2.3 發布頁](https://github.com/elvinzou/upyougo-releases/releases/tag/v1.2.3)下載並執行一次 `UpYouGo-Setup.exe`。設定與統計會保留。

## 常見問題

- **找不到新版本**：確認儲存庫為 elvinzou/upyougo-releases，網路可訪問 GitHub。預釋出版不會自動提示。
- **下載失敗**：當前版本仍可執行；稍後重試，或手動下載完整 ZIP 後選擇本機更新。
- **主面板初始化失敗**：檢查 Microsoft Edge WebView2 Runtime 是否已安裝；便攜版需完整解壓，不能只複製 EXE。
- **目錄沒有許可權**：選擇當前使用者可寫的獨立目錄，安裝程式不自動提權。
- **為什麼關閉視窗後仍提醒**：關閉面板不退出，系統匣選單可退出程式。
- **更新後倒數計時重置**：當前版本尚未接續更新前進度，按照啟動設定處理。

設定和記錄：`%APPDATA%\LumbarReminder`。WebView2 快取：`%LOCALAPPDATA%\UpYouGo\WebView2Data`。修改資料前先退出程式並自行備份原檔案。

## 語言切換

1.2.0 新增中文 / English 介面切換。在主面板右上角選擇語言，立即生效並記住選擇；既有使用者預設繼續使用簡體中文。切換保留計時進度、姿勢與統計，不改變中國工作日曆或其他日程設定。

涵蓋主面板、提醒設定、系統匣與桌寵選單、提醒氣泡、統計視窗及主程式更新提示。已開啟的統計視窗同步切換，英文氣泡標題避免截斷。

獨立安裝程式與維護工具仍為中文。程式更新或重新啟動仍不接續原倒數計時；切換語言本身不需重新啟動。
