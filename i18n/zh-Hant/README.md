## 安裝

1. 在 Releases 下載 **UpYouGo-Setup.exe**。
2. 選擇獨立、可寫的安裝目錄，例如 `D:\Apps\UpYouGo`，點選安裝。
3. 設定坐站時間及工作日程，開始計時。

需要 Windows x64、.NET Framework（建議 4.8）和 Microsoft Edge WebView2 Runtime。安裝程式不附帶完整 WebView2 Runtime。關閉主面板不會退出；右鍵系統匣小貓可退出。

## 功能

- 坐站交替計時，暫停/繼續、確認姿勢和稍後提醒。
- 像素貓陪伴，氣泡提醒不搶佔當前輸入焦點。
- 工作時段、星期、中國調休與可選午休。
- 鎖定畫面/睡眠處理，手動及全螢幕自動免打擾。
- 本機統計、行為回饋和開機啟動選項。
- 自訂目錄、新版提示、線上/本機更新及失敗回退。

## 線上更新

安裝版啟動後及每 6 小時檢查此儲存庫的正式 Release。點選系統匣更新通知或「版本与更新」（版本與更新），檢視說明後下載更新。程式先驗證檔案，再儲存退出並驗證新版；失敗恢復原安裝狀態。

`UpYouGo-Windows-x64.zip` 可用於便攜執行或本機更新。`.sha256` 是更新驗證檔案，普通使用者無需手動操作。GitHub 自動提供的 Source code 壓縮包僅包含本儲存庫文件，不是安裝包。

## 資料與限制

個人設定和統計留在 `%APPDATA%\LumbarReminder`，更新不刪除它們；這些記錄不上傳。聯網用於版本檢查、下載及日曆同步。

更新不接續原倒數計時，重新啟動遵循啟動設定。目前尚無完整解除安裝與舊版本自動清理入口。此儲存庫僅用於公開軟體分發和使用文件，完整開發原始碼保持私有。

問題回饋請描述 Windows 版本、應用版本、重現步驟及錯誤提示，勿在公開 Issue 中附帶個人資料或憑證。
