# Roadmap

The following are candidates, not promised delivery dates.

| Priority | Direction |
| --- | --- |
| P1 | Resume timer state across updates and restarts |
| P1 | More complete uninstall and old-version cleanup |
| P2 | Download cancellation, retry and update preferences |
| P2 | Executable signing and wider physical DPI/multi-monitor coverage |
| P2 | Further separation of timing/schedule rules from the desktop host |

Four companions, light interactions, edge docking and local character packs are delivered in the GitHub standalone 1.4.0 release. Store distribution is maintained separately. Future prices, paid features and mobile apps are not committed by this release.
