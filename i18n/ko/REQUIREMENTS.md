# 기능 요구사항 및 인수 기준

[English](../en/REQUIREMENTS.md) | [日本語](../ja/REQUIREMENTS.md) | **한국어** | [简体中文](../../docs/REQUIREMENTS.md) | [繁體中文](../zh-Hant/REQUIREMENTS.md)

기준: UpYouGo 1.1.1, 2026-09-22. 현재 Windows 데스크톱 제품을 설명합니다. 제안 단계의 기능은 [향후 계획](ROADMAP.md)을 참조하세요. 과거 PRD의 하드웨어 범위는 이번 버전에 포함되지 않습니다.

## 제품 목표와 사용 흐름

Windows에서 오랫동안 일하는 사용자에게 작업 방해를 줄인 앉기·서기 전환 알림을 제공합니다. 사용자가 실제 자세를 확인하며, 카메라나 센서로 일어섰는지 판단하지 않습니다.

처음 실행 → 시간과 근무 일정 설정 → 타이머 시작 → 고양이 옆 알림 → 일어서기·앉기 확인 → 다음 주기. 근무 시간 외, 점심시간, 자리 비움, 방해 금지 상황은 각각의 규칙에 따라 처리해 중복되거나 부적절한 알림을 줄입니다.

## 구현된 요구사항

| ID | 기능 | 인수 기준 |
| --- | --- | --- |
| R01 | 앉기·서기 타이머 | 시간 설정, 시작, 일시 정지, 재개, 다시 시작. 확인 동작 후에만 자세 단계를 전환 |
| R02 | 방해를 줄인 알림 | 고양이 근처에 표시하며 입력 포커스를 빼앗지 않음. 메인 화면과 일관된 디자인 |
| R03 | 다시 알림 | 2/5/10분 연기. 매초 화면 갱신에도 연기 상태 유지 |
| R04 | 근무 일정 | 근무 시간, 요일, 선택적 점심시간 설정. 일정 밖의 시간은 유효 앉기·서기 시간에 합산하지 않음 |
| R05 | 중국 휴일 달력 | 공휴일·대체 근무일 및 오늘 설정 재정의. 동기화 실패 시 캐시 유지, 지원되지 않는 연도는 요일 규칙 사용 |
| R06 | 자리 비움 | Windows 잠금·절전 시 타이머 정지. 중첩 이벤트 병합. 짧은 부재 후 재개, 긴 부재 후 사용자 선택 대기 |
| R07 | 방해 금지 | 수동 및 선택적 전체 화면 자동 중지를 독립 관리. 자동 중지가 끝나도 수동 설정은 취소하지 않음 |
| R08 | 로컬 통계 | 일·주·월·년 통계, 유효 구간과 알림 응답 피드백. 기록을 서버로 전송하지 않음 |
| R09 | 바탕 화면 고양이 | 드래그, 대기·상호작용 애니메이션, 알림 자세. 동작 줄이기 설정 고려 |
| R10 | 시작 설정 | Windows 시작 시 실행 및 자동 타이머 설정. 창 닫기는 종료가 아니며 트레이에서 종료 가능 |
| R11 | 설치 | 쓰기 가능한 전용 폴더 선택. 고정 실행 진입점과 바로가기 생성, 기존 개인 데이터 재사용 |
| R12 | 새 버전 확인 | 시작 시 및 6시간마다 공개 정식 릴리스 확인. 더 높은 버전만 알리고 사전 릴리스는 설치하지 않음 |
| R13 | 온라인 업데이트 | 설명을 보여 주고 사용자 요청 후 ZIP 다운로드. 해시·내부 목록 검증 뒤 저장·종료·새 버전 실행 |
| R14 | 로컬 업데이트 | 완전한 ZIP 사용. 누락, 경로 이탈, 중복, 해시 불일치, 같은 버전 번호의 다른 내용을 거부 |
| R15 | 롤백 | 메인 화면 로딩 및 짧은 생존 확인 후 확정. 실패 시 이전 상태 복원, 다음 실행 시 중단된 업데이트 복구, 수동 롤백 지원 |

## 현재 버전의 범위 밖

정식 모바일 앱, 기기 간 동기화, 클라우드 계정, 자동 자세 감지, 강제 온라인 업데이트, 업데이트 후 타이머 복원, 완전한 제거 프로그램은 제공되지 않습니다. ESP8266과 이전 브리지 코드는 과거 프로젝트로 남아 있으며 이 버전에 빌드되지 않습니다.

## 업데이트 오류와 데이터 처리

- 이전 버전 종료 전에 다운로드와 검증을 마치며, 실패하면 활성 버전을 바꾸지 않습니다.
- 저장 실패 시 기존 프로세스를 강제 종료하지 않고 유지합니다.
- 시작 검증 제한은 30초입니다. 이 업데이트 프로그램이 실행한 실패 프로세스만 종료합니다.
- 롤백은 개인 데이터를 이전·삭제·복원하지 않습니다. 호환되지 않는 데이터 형식 변경에는 먼저 백업 및 호환 계획이 필요합니다.
- 종료 인터페이스가 없는 이전 포터블 버전에는 트레이에서 종료하도록 안내합니다.
- 권한 부족 또는 파일 충돌 시 다른 폴더를 안내하며 자동으로 권한을 상승시키지 않습니다.

## 검증 및 지표

검증 범위는 각 릴리스 설명에 기록합니다. 응답 통계는 사용자의 확인에 기반하며 실제 활동량이나 건강 효과를 측정한 값이 아닙니다. 유지율, 건강상 이점, 공개 사용자 규모는 검증되지 않았으며 달성한 성과로 표현하지 않습니다.
