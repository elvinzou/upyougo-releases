## 1.2.3 — 2026-09-28

- 설치 파일이 다운로드 출처 표시를 유지 관리 프로그램에 복사하지 않도록 수정하여 일부 Windows 환경의 업데이트 창 실행 문제를 해결했습니다.
- 1.2.2에서 업데이트 창이 열리지 않으면 1.2.3 `UpYouGo-Setup.exe`를 한 번 실행하세요. 설정과 통계는 유지됩니다.

## 1.2.2 — 2026-09-28

- Windows가 업데이트 창 실행을 취소하거나 차단하면 처리되지 않은 .NET 예외 창 대신 오류와 수동 다운로드 주소를 표시합니다.

## 1.2.1 — 2026-09-28

- 트레이 메뉴에서 개인 데이터를 `.upyougo` 파일로 내보내고 검증 후 복원할 수 있습니다. 복원 전에 현재 데이터를 보관합니다.
- 알림 확인 버튼에 의도치 않게 나타나는 점선 포커스 테두리를 제거하고 마우스 및 키보드 동작은 유지했습니다.

## 1.2.0 — 2026-09-23

- 1.2.0에서 중국어 / English 화면 전환을 추가했습니다. 메인 패널 오른쪽 위에서 선택하면 즉시 적용되고 다음 실행에도 유지됩니다. 기존 사용자는 기본적으로 중국어를 유지합니다. 언어를 바꿔도 타이머, 자세, 통계, 중국 근무일 달력 및 일정은 바뀌지 않습니다.
- 메인 패널, 알림 설정, 트레이와 고양이 메뉴, 알림 말풍선, 통계 및 앱 내 업데이트 안내에 적용됩니다. 열려 있는 통계 창도 전환되며 영어 말풍선 제목이 잘리지 않도록 조정했습니다.

별도 설치 프로그램과 유지보수 도구는 계속 중국어입니다. 앱 업데이트나 재시작 시 기존 타이머는 이어지지 않습니다. 언어 전환 자체에는 재시작이 필요하지 않습니다.

## 1.1.1 — 2026-09-22

별도의 공개 릴리스 저장소를 통한 첫 배포입니다. 개발 소스는 계속 비공개로 유지합니다.

- 기본 업데이트 저장소를 `elvinzou/upyougo-releases`로 변경하고 이전 기본 설정과의 호환성을 추가했습니다.
- 요구사항, 구조, 개발·테스트, 배포 절차, 향후 계획 문서를 정리했습니다.
- Windows 빌드와 업데이트 기능 검사를 위한 지속적 통합을 추가했습니다.

이전에 로컬로 제공한 기능을 포함합니다: 앉기·서기 알림, 픽셀 고양이, 근무 일정·중국 대체 근무일·점심시간, 자리 비움과 전체 화면 알림 중지, 로컬 통계, 사용자 지정 설치 경로, 새 버전 알림, 온라인·로컬 업데이트, 롤백.

알려진 제한: 업데이트 후 카운트다운을 복원하지 않습니다. 전체 WebView2 Runtime은 포함되지 않습니다. 완전한 제거 및 이전 버전 정리 기능은 아직 없습니다. 실행 파일은 Authenticode 서명이 되어 있지 않습니다.
