| 우선순위 | 제안 | 가치 및 인수 방향 |
| --- | --- | --- |
| P1 | 업데이트 후 타이머 이어가기 | 자세 단계, 남은 시간, 연기·정지 상태를 업데이트와 롤백 후 복원하고 만료된 세션을 명확히 처리 |
| P1 | 데이터 내보내기와 복원 | 설정·통계를 내보내고 가져오기 전 검증과 기존 데이터 백업 수행 |
| P1 | 설치 유지보수 | 제거 기능, 이전 버전 정리, 설치 폴더 이전. 개인 데이터는 기본적으로 보존 |
| P2 | 다운로드 취소·재개 | 취소를 지원하고 불안정한 연결 재시도 시 타이머를 방해하거나 불필요한 임시 파일을 남기지 않음 |
| P2 | 업데이트 설정과 채널 | 자동 확인 끄기, 특정 버전 건너뛰기, 유지보수 프로그램 자체의 호환 업데이트 방식 |
| P2 | 배포 신뢰성과 호환성 | 실행 파일 서명, 다양한 DPI·다중 모니터·Windows 환경 검증 |
| P2 | 핵심 규칙 추가 분리 | WinForms와 독립된 타이머·일정·기록 경계를 만들어 향후 모바일 재사용 준비 |
| 검증 필요 | 정식 모바일 앱 | 백그라운드 알림, 권한, 상호작용을 검증한 뒤 범위 결정. 데스크톱 창과 설치 프로그램을 그대로 옮기지 않음 |

안정적인 배포와 데이터 복원성을 먼저 확보한 뒤 기능과 플랫폼을 확장합니다. 하드웨어 연동은 과거 프로젝트로 유지하며 위 기본 개발 순서에는 포함하지 않습니다.
