# UpYouGo（起身啦）

[English](../en/README.md) | [日本語](../ja/README.md) | **한국어** | [简体中文](../../README.md) | [繁體中文](../zh-Hant/README.md)

> 1.2.0에서 중국어 / English 화면 전환을 추가했습니다. 메인 패널 오른쪽 위에서 선택하면 즉시 적용되고 다음 실행에도 유지됩니다. 기존 사용자는 기본적으로 중국어를 유지합니다. 언어를 바꿔도 타이머, 자세, 통계, 중국 근무일 달력 및 일정은 바뀌지 않습니다.

앉기와 서기를 번갈아 안내하는 Windows 알림 앱과 바탕 화면 고양이입니다. 근무 일정, 점심시간, 중국 공휴일 및 대체 근무일, 방해 금지, 로컬 통계를 지원합니다.

## 시간이 되면 고양이 곁에서 알려줘요

<p align="center"><img src="../../assets/reminder-bubbles.png" width="900" alt="고양이 양옆에 표시하는 알림 구성요소 미리보기. 위는 일어서기, 아래는 앉기 알림이며 확인과 다시 알림 버튼 포함"></p>

*알림 구성요소 미리보기입니다. 위는 일어서기, 아래는 앉기 알림이며 고양이 좌우의 배치를 보여 줍니다.*

- **입력을 계속할 수 있어요:** 말풍선이 입력 포커스를 빼앗지 않습니다.
- **다음 동작이 분명해요:** “我站起来了”는 일어섰음을, “我坐下了”는 앉았음을 확인합니다.
- **지금 바쁘다면:** 2 / 5 / 10분 다시 알림이나 방해 금지를 사용하세요.

## 고양이는 어떻게 반응하나요?

| 상황 | 동작과 반응 |
| --- | --- |
| 조작 없이 함께 있을 때 | 마우스를 움직이지 않아도 고개 들기, 꼬리 움직이기, 눈 깜박이기를 번갈아 합니다 |
| 포인터가 가까워질 때 | 고개를 들고 포인터가 있는 쪽으로 갸웃합니다 |
| 클릭해 쓰다듬을 때 | 눈을 감고 머리를 비비며 앞발을 번갈아 움직인 뒤 턱을 들고 다시 편안해집니다 |
| 한 번 더 쓰다듬을 때 | 현재 동작을 마친 뒤 최대 한 차례 더 반응하며 처음부터 반복해서 재생하지 않습니다 |
| 일어설 시간이 될 때 | 앞발을 뻗고 몸을 펼쳐 일어서기 알림과 함께 기지개를 켭니다 |
| 앉을 시간이 될 때 | 몸을 편안히 모으는 동작으로 앉기 알림을 함께합니다 |
| 가끔 보이는 큰 동작 | 하품, 기지개, 앞발을 들어 인사하기. 동작 사이에는 쉬는 시간이 있습니다 |
| 드래그·일시 정지 | 알맞은 위치로 옮길 수 있고 일시 정지 중에는 자율 동작 빈도가 줄어듭니다 |

앱은 Windows 동작 줄이기 설정을 따릅니다. 자율 애니메이션을 멈추고 쓰다듬을 때의 짧은 정적 반응은 남깁니다. 고양이는 신체 자세를 감지하지 않으며 각 타이머 단계는 사용자가 직접 확인합니다.

## 설치

1. Releases에서 **UpYouGo-Setup.exe**를 다운로드합니다.
2. `D:\Apps\UpYouGo`처럼 쓰기 가능한 전용 설치 폴더를 선택합니다.
3. 앉아 있는 시간, 서 있는 시간과 근무 일정을 설정하고 타이머를 시작합니다.

Windows x64, .NET Framework(4.8 권장), Microsoft Edge WebView2 Runtime이 필요합니다. 설치 프로그램에는 전체 WebView2 Runtime이 포함되지 않습니다. 메인 창을 닫아도 앱은 종료되지 않습니다. 시스템 트레이의 고양이를 마우스 오른쪽 버튼으로 클릭해 종료하세요.

## 기능

- 앉기·서기 교대 타이머, 일시 정지·재개, 자세 확인, 다시 알림.
- 픽셀 고양이와 입력 포커스를 빼앗지 않는 말풍선 알림.
- 근무 시간, 요일, 중국 공휴일·대체 근무일, 선택적 점심시간.
- 화면 잠금·절전 처리, 수동 방해 금지, 선택적 전체 화면 자동 알림 중지.
- 로컬 통계, 행동 피드백, 시작 설정.
- 사용자 지정 설치 경로, 새 버전 알림, 온라인·로컬 업데이트, 실패 시 롤백.

## 온라인 업데이트

설치된 앱은 시작 시와 이후 6시간마다 이 저장소의 정식 릴리스를 확인합니다. 트레이 알림 또는 “版本与更新”(버전 및 업데이트)을 열어 변경 내용을 확인한 뒤 업데이트를 다운로드합니다. 파일 검증 후 기록을 저장하고 종료하며, 새 버전의 시작을 확인합니다. 시작에 실패하면 업데이트 전 설치 상태로 돌아갑니다.

`UpYouGo-Windows-x64.zip`은 포터블 실행과 로컬 업데이트에 사용할 수 있습니다. `.sha256` 파일은 업데이트 기능이 자동으로 사용합니다. GitHub가 자동 생성하는 Source code 압축 파일은 이 저장소의 문서이며 앱 설치 파일이 아닙니다.

## 데이터 및 제한 사항

설정과 통계는 `%APPDATA%\LumbarReminder`에 저장됩니다. 업데이트는 이 데이터를 삭제하거나 업로드하지 않습니다. 네트워크는 버전 확인, 다운로드, 달력 동기화에 사용됩니다.

업데이트 전 카운트다운은 이어지지 않으며, 다시 실행하면 시작 설정을 따릅니다. 완전한 제거 프로그램과 이전 버전 자동 정리 기능은 아직 없습니다. 이 저장소는 실행 파일과 사용자 문서만 공개하며 개발 소스는 비공개로 유지합니다.

문제 신고 시 Windows 버전, 앱 버전, 재현 단계와 오류 메시지를 적어 주세요. 공개 Issue에 개인 기록이나 인증 정보를 포함하지 마세요.
