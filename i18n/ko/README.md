# 起身啦 · UpYouGo

**집중하는 하루에, 일어설 타이밍을.**

Windows용 앉기·서기 전환 알림과 데스크톱 친구입니다. 업무 일정에 맞춘 알림, 가벼운 상호작용, 로컬 기록을 제공합니다. 계정 등록이 필요하지 않습니다.

**[1.4.0 다운로드](https://github.com/elvinzou/upyougo-releases/releases/latest)** · [사용 안내](USER_GUIDE.md) · [English](../en/README.md) · [简体中文](../../README.md)

## 나와 맞는 데스크톱 친구를 선택하세요

![Desktop companions](../../assets/desktop-companions.png)

픽셀 고양이, 九千岁, 손그림 카피바라, 작은 캐릭터 등 네 가지 외형을 제공합니다. 쓰다듬기, 간식, 공놀이, 이름 변경, 70%–150% 크기 조절과 독립적인 동작 미리보기를 지원합니다. 화면 좌우 가장자리에 숨겨 두었다가 마우스를 가까이 대거나 알림 시간이 되면 펼쳐집니다.

## 업무 흐름에 맞춘 알림

![Companion speech bubbles](../../assets/companion-dialogs.png)

- 앉아 있는 시간과 서 있는 시간을 설정하고 일시 정지, 재개, 자세 확인, 다시 알림을 사용할 수 있습니다.
- 업무 시간, 요일, 선택적 점심시간, 중국 공휴일과 대체 근무일, 당일 일정 변경을 지원합니다.
- 입력 포커스를 빼앗지 않는 말풍선, 수동 방해 금지, 전체 화면 자동 조용한 모드, 동작 줄이기 설정.
- JSON + PNG 캐릭터 팩을 폴더나 ZIP으로 가져옵니다. 일반 사진에서 애니메이션을 자동 생성하지는 않습니다.
- 설정, 통계, 행동 기록은 로컬에 저장하며 백업과 복원을 지원합니다. 추가 캐릭터 이미지는 별도로 보관해야 합니다.

## 설치 및 시작

Releases에서 UpYouGo-Setup.exe를 내려받아 쓰기 가능한 전용 폴더에 설치합니다. 시간과 업무 일정을 설정한 뒤 메인 화면 하단의 펫 설정에서 외형을 선택하세요. 포터블 버전은 ZIP 전체를 풀어야 합니다.

## 실행 환경 및 지원 범위

Windows x64, .NET Framework(4.8 권장), Microsoft Edge WebView2 Runtime이 필요합니다. Windows 10/11을 권장합니다. 앱 UI는 중국어 간체와 영어를 지원하며 설치 프로그램과 유지 관리 도구는 중국어입니다. 한국어 문서가 한국어 UI 지원을 의미하지는 않습니다.

업데이트나 재시작 후 이전 카운트다운이 이어지지는 않습니다. 설정과 기록은 유지됩니다. 1.4.0에는 네 가지 외형, 가장자리 숨기기, 캐릭터 팩, 새 말풍선이 추가되었습니다. 임시 전체 화면 창을 닫은 후에도 펫이 추가로 10초간 숨겨지는 문제를 수정했습니다. WeChat 버전별 캡처 동작과 실제 다중 모니터·혼합 DPI 환경은 별도 확인이 필요합니다.
