# 사용 안내

## 처음 설치 및 이전 버전에서 전환

Release의 UpYouGo-Setup.exe를 다운로드하고 쓰기 가능한 전용 폴더를 선택합니다. 업데이트 인터페이스를 지원하는 이전 버전은 자동으로 저장하고 종료합니다. 그보다 오래된 포터블 버전은 먼저 트레이 고양이 메뉴에서 종료해야 합니다. 기존 설정과 통계는 유지됩니다.

## 일상적인 알림

앉아 있는 시간, 서 있는 시간과 근무 시간을 설정한 뒤 시작합니다. 알림이 나오면 일어섰거나 앉았음을 확인해 다음 단계로 넘어갑니다. 바로 움직이기 어려우면 다시 알림이나 방해 금지를 사용하세요. 자세는 사용자가 직접 확인하며 앱이 신체 움직임을 감지하지는 않습니다.

일정 설정에서 요일, 중국 공휴일·대체 근무일, 오늘의 근무·휴무 재정의, 선택적 점심시간을 설정할 수 있습니다. 잠금과 절전 중에는 타이머를 멈추며, 오래 자리를 비웠다면 계속할지 다시 시작할지 선택합니다. 전체 화면 자동 알림 중지는 끌 수 있습니다.

메인 화면의 통계에서 로컬 시간 기록과 행동 피드백을 확인합니다. 창을 닫아도 트레이와 고양이는 계속 실행됩니다. 완전히 종료하려면 트레이 메뉴를 사용하세요.

## 업데이트와 롤백

트레이 → “版本与更新”(버전 및 업데이트)에서 새 버전을 확인하고 릴리스 설명을 읽은 뒤 다운로드할 수 있습니다. 완전한 로컬 업데이트 ZIP을 선택할 수도 있습니다. 설치 프로그램은 파일 검증 후 저장하고 종료합니다. 새 버전의 시작 검증에 실패하면 이전 설치 상태를 복원합니다. 앱을 롤백해도 개인 데이터는 과거 상태로 돌아가지 않습니다.

1.1.1은 이전 기본 비공개 업데이트 저장소를 이 공개 저장소로 전환합니다. 처음 이 배포 채널로 전환할 때는 유지보수 프로그램도 갱신되도록 해당 릴리스의 Setup을 실행하세요.

## 자주 발생하는 문제

- **새 버전을 찾을 수 없음:** 저장소가 `elvinzou/upyougo-releases`인지, GitHub에 접속할 수 있는지 확인합니다. 사전 릴리스는 자동 알림 대상이 아닙니다.
- **다운로드 실패:** 현재 앱은 계속 사용할 수 있습니다. 나중에 다시 시도하거나 전체 ZIP을 수동으로 다운로드해 로컬 업데이트를 선택하세요.
- **메인 화면 초기화 실패:** Microsoft Edge WebView2 Runtime 설치 여부를 확인하세요. 포터블 버전은 전체 압축을 풀어야 하며 EXE만 복사하면 안 됩니다.
- **설치 권한 부족:** 현재 사용자가 쓸 수 있는 전용 폴더를 선택하세요. 설치 프로그램은 관리자 권한을 자동으로 요청하지 않습니다.
- **창을 닫아도 알림이 계속됨:** 창 닫기는 종료가 아닙니다. 트레이 메뉴에서 종료하세요.
- **업데이트 후 카운트다운 초기화:** 업데이트 전 남은 시간 복원은 아직 구현되지 않았습니다. 재실행 시 시작 설정을 따릅니다.

설정 및 기록: `%APPDATA%\LumbarReminder`. WebView2 캐시: `%LOCALAPPDATA%\UpYouGo\WebView2Data`. 데이터를 직접 수정하기 전에는 앱을 종료하고 원본 파일을 백업하세요.
