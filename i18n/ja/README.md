# 起身啦 · UpYouGo

**集中する時間に、立ち上がるきっかけを。**

Windows 向けの座る・立つ切り替えリマインダーとデスクトップの仲間。勤務時間に合わせた通知、気軽なふれあい、ローカルの記録を備えています。アカウント登録は不要です。

**[1.4.2 をダウンロード](https://github.com/elvinzou/upyougo-releases/releases/latest)** · [使い方](USER_GUIDE.md) · [English](../en/README.md) · [简体中文](../../README.md)

## 自分に合うデスクトップの仲間を

![Desktop companions](../../assets/desktop-companions.png)

ピクセル猫、九千岁、手描きのカピバラ、デフォルメキャラクターの 4 種類。なでる、おやつ、ボール遊び、名前の変更、70%〜150% のサイズ調整、独立した動作プレビューに対応。左右の端にしまい、マウスを近づけたり通知時刻になったりすると展開します。

## 仕事のリズムに合わせた通知

![Companion speech bubbles](../../assets/companion-dialogs.png)

- 座る時間と立つ時間を設定し、一時停止・再開・姿勢の確認・スヌーズを利用できます。
- 勤務時間、曜日、任意の昼休み、中国の祝日と振替出勤日、当日の上書きに対応。
- 入力フォーカスを奪わない吹き出し、手動のおやすみモード、全画面時の静音、動きを減らす設定。
- JSON + PNG 形式のキャラクターパックをフォルダーまたは ZIP から読み込み。写真から自動でアニメーションを作る機能ではありません。
- 設定・統計・行動記録はローカル保存。バックアップと復元に対応し、追加した画像素材は別途保管します。

## インストール

Releases から UpYouGo-Setup.exe をダウンロードし、書き込み可能な専用フォルダーにインストールします。時間と勤務日程を設定し、メイン画面下部のペット設定から仲間を選びます。ポータブル版は ZIP 全体を展開してください。

## 動作環境と提供範囲

Windows x64、.NET Framework（4.8 推奨）、Microsoft Edge WebView2 Runtime が必要です。Windows 10/11 を推奨します。アプリの表示言語は簡体字中国語と英語、インストーラーとメンテナンスツールは中国語です。日本語の文書は日本語 UI の提供を意味しません。

1.4.2 ではペット描画の安定性を改善しました。同じ勤務時間内の短い中断は保存済みの進行状況から再開し、長い中断や勤務時間の変更後は確認を求めます。1.4.0 以前からの初回更新では旧進行状況は復元できません。1.4.0 では 4 種類の仲間、端への収納、パックの読み込み、新しい吹き出しを追加。一時的な全画面ウィンドウを閉じた後もペットが 10 秒間隠れる問題を修正しました。WeChat の各バージョンや実機の複数画面・混在 DPI 環境は個別の確認が必要です。
