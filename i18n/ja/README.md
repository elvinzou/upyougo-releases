## 時間になったら、猫のそばでお知らせ

<p align="center"><img src="../../assets/reminder-bubbles.png" width="900" alt="猫の左右に表示する通知部品のプレビュー。上段は立つ通知、下段は座る通知で、確認とスヌーズの操作がある"></p>

*通知部品のプレビューです。上段は立つ通知、下段は座る通知で、猫の左右それぞれの配置を示しています。*

- **入力を続けられる：** 吹き出しは入力フォーカスを奪いません。
- **次の操作が明確：**「我站起来了」で立ったことを、「我坐下了」で座ったことを確認します。
- **今は忙しいときに：** 2 / 5 / 10 分のスヌーズ、または通知停止を使えます。

## 猫はどう反応する？

| 場面 | 動作と反応 |
| --- | --- |
| 操作せずに見守る | 見上げる、尻尾を動かす、まばたきを自発的に繰り返します |
| ポインターを近づける | 顔を上げ、ポインターがある側へ首をかしげます |
| クリックしてなでる | 目を閉じ、頭をすり寄せ、前足を交互に動かし、あごを上げてからくつろぎます |
| もう一度なでる | 今の動きを最後まで行い、最大でもう一巡だけ追加。毎回最初から再生しません |
| 立つ時間になる | 前足を伸ばして体を広げ、立つ通知に合わせて伸びをします |
| 座る時間になる | 体を落ち着かせる動きで、座る通知を添えます |
| ときどきの大きな動き | あくび、伸び、前足を上げた挨拶。動きの間には休みがあります |
| ドラッグ・一時停止 | 好きな位置へ移動でき、一時停止中は自発的な動作が少なくなります |

Windows の動きを減らす設定に従い、自発的なアニメーションを止め、なでたときの短い静止ポーズを残します。猫は身体の姿勢を検出しないため、計時の段階は利用者自身が確認します。

## インストール

1. Releases から **UpYouGo-Setup.exe** をダウンロードします。
2. `D:\Apps\UpYouGo` など、書き込み可能な専用フォルダーを選んでインストールします。
3. 座る時間、立つ時間、勤務スケジュールを設定し、タイマーを開始します。

Windows x64、.NET Framework（4.8 推奨）、Microsoft Edge WebView2 Runtime が必要です。インストーラーに完全な WebView2 Runtime は含まれません。メイン画面を閉じてもアプリは終了しません。タスクトレイの猫を右クリックして終了してください。

## 機能

- 座る・立つの交互タイマー、一時停止・再開、姿勢の確認、スヌーズ。
- ピクセルアートの猫と、入力フォーカスを奪わない通知吹き出し。
- 勤務時間、曜日、中国の祝日・振替出勤日、任意の昼休み。
- ロック・スリープ時の処理、手動の通知停止、全画面表示時の自動通知停止。
- ローカル統計、行動の振り返り、起動設定。
- インストール先の選択、新版通知、オンライン・ローカル更新、失敗時のロールバック。

## オンライン更新

インストール版は起動時と、その後 6 時間ごとにこのリポジトリの正式リリースを確認します。トレイ通知、または「版本与更新」（バージョンと更新）を開き、変更内容を確認して更新をダウンロードします。ファイル検証後に記録を保存して終了し、新版の起動を検証します。起動に失敗すると更新前のインストール状態に戻ります。

`UpYouGo-Windows-x64.zip` はポータブル実行とローカル更新に使えます。`.sha256` は更新機能が自動で使用します。GitHub が自動生成する Source code の圧縮ファイルは、このリポジトリの文書であり、アプリ本体ではありません。

## データと制限

設定と統計は `%APPDATA%\LumbarReminder` に保存され、更新で削除・アップロードされることはありません。通信はバージョン確認、ダウンロード、カレンダー同期に使用します。

更新前のカウントダウンは引き継がず、再起動後は起動設定に従います。完全なアンインストーラーと旧バージョンの自動削除は未実装です。このリポジトリは実行ファイルと利用者向け文書を公開するもので、開発用ソースコードは非公開です。

不具合報告には Windows とアプリのバージョン、再現手順、エラーを記載してください。公開 Issue に個人の記録や認証情報を含めないでください。
