## 初回インストールと移行

Release の UpYouGo-Setup.exe をダウンロードし、書き込み可能な専用フォルダーを選びます。更新用インターフェースを持つ旧版は自動で保存して終了します。それ以前のポータブル版は、先にトレイの猫から終了してください。既存の設定と統計は保持されます。

## 日常のリマインダー

座る・立つ時間と勤務時間を設定し、開始します。通知が出たら立った・座ったことを確認して次の段階へ進みます。都合が悪い場合はスヌーズや通知停止を使用します。姿勢は利用者が確認するもので、アプリが身体の動きを検出するわけではありません。

スケジュール設定では曜日、中国の祝日・振替出勤日、今日の勤務・休みの上書き、任意の昼休みを設定できます。ロックやスリープ中は計時を停止し、長時間離れた場合は再開か最初からの開始を選びます。全画面表示時の自動通知停止は無効にできます。

メイン画面の統計から、ローカルの時間記録や行動の振り返りを確認できます。画面を閉じてもトレイと猫は動作を続けます。完全に終了するにはトレイメニューを使います。

## 更新とロールバック

トレイ →「版本与更新」（バージョンと更新）から、新版の確認、リリースノートの閲覧、ダウンロードができます。完全なローカル更新 ZIP を選ぶこともできます。検証後に保存して終了し、新版の起動検証に失敗すると元のインストール状態に戻ります。アプリのロールバックで個人データは巻き戻りません。

1.1.1 は旧既定の非公開更新元を、この公開リポジトリに移行します。初めてこの配信先へ移行する際は、保守プログラムも更新できるよう、このリリースの Setup を実行してください。

## よくある問題

- **新版が見つからない：** リポジトリが `elvinzou/upyougo-releases` で、GitHub に接続できるか確認してください。プレリリースは自動通知の対象外です。
- **ダウンロードに失敗：** 現在のアプリは引き続き使えます。後で再試行するか、完全な ZIP を手動で取得してローカル更新を選んでください。
- **メイン画面の初期化に失敗：** Microsoft Edge WebView2 Runtime を確認してください。ポータブル版は全ファイルを展開し、EXE だけをコピーしないでください。
- **インストール権限がない：** 現在の利用者が書き込める専用フォルダーを選びます。自動で管理者権限を要求しません。
- **画面を閉じても通知される：** 画面を閉じる操作は終了ではありません。トレイから終了してください。
- **更新後にカウントダウンがリセット：** 更新前の残り時間の復元は未実装です。再起動後は起動設定に従います。

設定と記録：`%APPDATA%\LumbarReminder`。WebView2 キャッシュ：`%LOCALAPPDATA%\UpYouGo\WebView2Data`。データを編集する前にアプリを終了し、元のファイルをバックアップしてください。
