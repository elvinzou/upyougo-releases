# 今後の計画

[English](../en/ROADMAP.md) | **日本語** | [한국어](../ko/ROADMAP.md) | [简体中文](../../docs/ROADMAP.md) | [繁體中文](../zh-Hant/ROADMAP.md)

以下は提案であり、実装済み機能や確定した日程ではありません。現状は[機能要件](REQUIREMENTS.md)を参照してください。

| 優先度 | 提案 | 目的と受け入れの方向性 |
| --- | --- | --- |
| P1 | 更新後の計時引き継ぎ | 姿勢、残り時間、スヌーズ・停止状態を更新とロールバック後に復元し、期限切れの状態を明確に処理 |
| P1 | データの書き出しと復元 | 設定・統計を出力し、復元前に検証と既存データのバックアップを行う |
| P1 | インストール保守 | アンインストール、旧版の容量整理、インストール先移行。個人データは既定で保持 |
| P2 | ダウンロード中止・再開 | 中止を可能にし、不安定な通信でも計時を妨げず、不要な一時ファイルを残さない |
| P2 | 更新設定と配信先 | 自動確認の無効化、特定版のスキップ、保守プログラム自体の互換更新方式 |
| P2 | 配布の信頼性と互換性 | 実行ファイル署名、各種 DPI・複数画面・Windows 環境での検証 |
| P2 | 中核ルールの分離 | WinForms に依存しない計時・予定・記録の境界を作り、将来のモバイル版に備える |
| 要検証 | 正式モバイル版 | バックグラウンド通知、権限、操作要件を検証して範囲を決定。デスクトップの窓やインストーラーを再現しない |

安定した配布とデータ復元性を先に整え、その後に機能とプラットフォームを広げます。ハードウェア連携は過去の工程として維持し、この標準の開発順序には含めません。
