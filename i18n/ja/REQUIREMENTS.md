# 機能要件と受け入れ基準

[English](../en/REQUIREMENTS.md) | **日本語** | [한국어](../ko/REQUIREMENTS.md) | [简体中文](../../docs/REQUIREMENTS.md) | [繁體中文](../zh-Hant/REQUIREMENTS.md)

基準：UpYouGo 1.1.1、2026-09-22。現在の Windows デスクトップ製品を対象とします。提案段階の要件は[今後の計画](ROADMAP.md)を参照してください。過去の PRD にあるハードウェア範囲は本版に含まれません。

## 目的と利用の流れ

Windows で長時間働く人に、作業を妨げにくい座位・立位の切り替え通知を提供します。姿勢は利用者が確認し、カメラやセンサーで立ったことを判定しません。

初回起動 → 時間と勤務予定を設定 → 計時開始 → 猫の横に通知 → 立った・座ったことを確認 → 次の周期。勤務時間外、昼休み、離席、通知停止の各ルールで、不適切な時間帯の通知や重複を防ぎます。

## 実装済み要件

| ID | 機能 | 受け入れ基準 |
| --- | --- | --- |
| R01 | 座位・立位タイマー | 時間設定、開始、一時停止、再開、やり直し。確認操作後にのみ姿勢の段階を切り替える |
| R02 | 作業を妨げにくい通知 | 猫の近くに表示し、入力フォーカスを奪わない。メイン画面と外観を統一 |
| R03 | スヌーズ | 2/5/10 分延長。毎秒の更新でスヌーズ状態が失われない |
| R04 | 勤務スケジュール | 時間帯、曜日、任意の昼休みを設定。予定外の時間を有効な座位・立位時間に加算しない |
| R05 | 中国の休日 | 祝日・振替出勤日と当日の上書き。同期失敗時はキャッシュを保持し、対象外の年は曜日ルールへ戻す |
| R06 | 離席 | Windows ロック・スリープ時に計時を凍結。重複イベントを統合。短時間は再開し、長時間は選択待ち |
| R07 | 通知停止 | 手動と任意の全画面自動停止を独立管理。自動停止終了時も手動設定を解除しない |
| R08 | ローカル統計 | 日・週・月・年表示、有効区間と通知応答の振り返り。記録をサーバーに送らない |
| R09 | デスクトップの猫 | ドラッグ、待機・対話アニメーション、通知姿勢。動きを減らす設定を考慮 |
| R10 | 起動設定 | Windows 起動時の実行と自動計時を設定。画面を閉じても終了せず、トレイから終了できる |
| R11 | インストール | 書き込み可能な専用フォルダーを選択。固定ランチャーとショートカットを作成し、既存データを継続利用 |
| R12 | 新版検出 | 起動時と 6 時間ごとに公開正式版を確認。新しい版だけ通知し、プレリリースはインストールしない |
| R13 | オンライン更新 | 説明を表示し、利用者の操作で ZIP を取得。ハッシュと内部一覧を検証してから保存・終了・新版起動 |
| R14 | ローカル更新 | 完全な ZIP を使用。欠落、パス逸脱、重複、ハッシュ不一致、同番号で異なる内容を拒否 |
| R15 | ロールバック | 主画面の読み込みと短時間の生存確認後に確定。失敗時は旧状態へ戻し、次回起動で中断を復旧。手動でも戻せる |

## 本版の対象外

正式なモバイル版、端末間同期、クラウドアカウント、姿勢自動検出、強制オンライン更新、更新後の残り時間復元、完全なアンインストーラーは未提供です。ESP8266 や旧ブリッジは過去の工程として残し、本版には組み込みません。

## 更新時の異常とデータの扱い

- 旧版の終了前にダウンロードと検証を完了し、失敗時は有効な版を切り替えません。
- 保存できない場合は旧プロセスを動作させたままにし、強制終了しません。
- 起動検証は 30 秒でタイムアウトし、この更新機能が起動した失敗プロセスだけを終了します。
- ロールバックでは個人データを移行・削除・復元しません。非互換な形式変更には事前のバックアップと互換計画が必要です。
- 終了インターフェースのない旧ポータブル版には、トレイから終了するよう案内します。
- 権限不足やファイル競合時は別フォルダーを案内し、自動で権限昇格しません。

## 検証と指標

検証範囲はリリースノートを参照してください。応答統計は利用者の確認に基づき、実際の運動量や健康効果を測ったものではありません。継続率、健康効果、公開利用者数は未検証であり、達成済みとは扱いません。
